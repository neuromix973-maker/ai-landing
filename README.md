# EXCAVATOR PRO Android

Android APK wrapper for **EXCAVATOR PRO v15.12.0**.

- Web app: https://excavator-pro.pages.dev/
- JavaScript / DOM Storage / cookies enabled
- Android file and photo picker
- Geolocation permission support
- External phone / MAX / browser links
- Android Back navigation
- GitHub Actions builds an installable debug APK

The APK is built as a debug package so no private release signing key is stored in this public repository.

Generated artifact: **EXCAVATOR_PRO_v15_12.apk**
